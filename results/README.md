# Results (paper-backing, reproducible)

This directory holds the **canonical, committed** evaluation artifacts that back the
paper's reported numbers. Everything here is regenerated by `evaluate.py`, which now
persists its metrics (previously they existed only in the console and as throwaway
PNGs under the git-ignored `output/`).

## Reproduce the single-split result

```bash
# from repo root, with the venv active and JAAD present under
# Pedistrian_intent_detection/JAAD/
python adas_pipeline/evaluate.py --videos 150 --threshold 0.65
```

This writes into this folder:

- `eval_report.json` — machine-readable metrics + run metadata (videos, seed,
  threshold, obs_len, tte, confusion counts).
- `eval_report.md` — human-readable metrics table and confusion matrix.
- `roc_curve.png`, `pr_curve.png`, `confusion_matrix.png`, `early_prediction.png`
  (and `confidence_dist.png` if present) — the figures used in the paper.

## Why the command matters

- `--videos 150` — the paper's confusion matrix has **393 test windows**; the
  default `--videos 40` yields far fewer (~98) and different numbers.
- `--threshold 0.65` — the paper's operating point. The shipped model's baked
  threshold is 0.500; pass `--threshold 0.65` to match the paper. The run is
  deterministic (`--seed 42`, identical split to training).
